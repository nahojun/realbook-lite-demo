# REALBOOK Lite

REALBOOK Lite는 개인, 교육, 연구, 비상업 목적 사용에 한해 무료로 사용할 수 있습니다. 상업적 사용에는 유료 라이선스가 필요합니다.

영어 메인 문서: [README.md](./README.md)

REALBOOK Lite는 REALBOOK 리더 인터페이스의 공개 데모 및 평가용 빌드입니다. 브라우저에서 로컬 PDF를 열고, 양면 펼침, 페이지 적층, 페이지 컬 피드백, 페이지 썸네일, PDF Outline 탐색, 마우스 줌, Reading Lamp, Previous / Next / Return 기능을 제공합니다.

이 저장소는 정적 JavaScript 배포 패키지입니다. REALBOOK 원본 개발 저장소가 아닙니다. TypeScript 원본, 내부 개발 문서, 테스트, 보정 데이터, replay trace, private package 정보, source map은 포함하지 않습니다.

## 사용 방법

정적 웹 서버 또는 GitHub Pages에서 `index.html`을 여십시오. **Open PDF** 버튼으로 기기의 로컬 PDF를 선택하면 브라우저 안에서 PDF가 처리됩니다.

배포에는 Node.js 런타임, 백엔드 서버, 데이터베이스, OCR 서버, 업로드 서버, PDF 렌더링 서버가 필요하지 않습니다.

## 비상업 사용

다음 사용은 허용됩니다.

- 개인 독서
- 교육
- 연구
- 비상업적 개인 평가

상업 사용에는 SODEC의 별도 유료 라이선스가 필요합니다.
